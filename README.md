# 나만의 루틴

iPhone과 iPad를 우선 지원하는 한국어 오프라인 우선 PWA입니다. 데이터는 브라우저 저장소에만 보관합니다.

## 실행

이 폴더를 HTTPS 정적 호스팅에 올리거나 로컬 웹 서버로 열어 주세요. PWA 설치와 서비스 워커는 `file://` 주소에서 동작하지 않습니다. 서버가 제공되기 전에도 페이지 구성 파일은 확인할 수 있지만, 브라우저별 PWA 동작은 HTTPS 또는 `localhost`에서 확인해야 합니다.

Safari에서 사이트를 연 뒤 공유 메뉴의 **홈 화면에 추가**를 선택하면 설치할 수 있습니다. 설치 후 한 번 온라인 상태에서 열면 앱 화면과 스타일 파일이 캐시에 저장되어 오프라인에서도 열립니다.

## 저장과 백업

- 루틴과 완료 기록은 현재 브라우저의 IndexedDB에 저장합니다. IndexedDB를 사용할 수 없는 환경에서는 localStorage를 사용합니다.
- 자동 계정 동기화나 서버 저장은 없습니다.
- 설정 화면에서 전체 JSON 백업을 내려받고 복원하거나, 기록을 CSV로 내보낼 수 있습니다.
- 브라우저 저장소는 기기 분실이나 사용자의 브라우저 데이터 삭제에 대비한 백업을 대체하지 않습니다.

## 알림 제한

요약 알림은 사용자가 권한을 허용한 경우 앱이 실행 중일 때 브라우저 알림을 요청합니다. 서버를 사용하지 않으므로 앱이 종료된 상태에서 알림을 정해진 시각에 전달할 수 없습니다. iOS·iPadOS의 웹 푸시는 홈 화면에 설치된 웹앱과 서버 발송 구성이 필요하므로 이 앱에서는 사용하지 않습니다.

## 포함 기능

- 매일, 매주, 격주, 몇 일마다, 매월 반복 일과와 쉬는 요일 설정
- 날짜별 완료 체크, 달력 기록, 루틴별 스트릭
- 주간 완료율과 최근 26주 그래프
- 개인 할 일, 미래 일정, 재사용 템플릿
- 전체 JSON 백업, 병합/교체 복원, CSV 내보내기
- 7일 경과 시 외부 백업 안내
